# קרוב (ProNear) — פלטפורמה לאיתור אנשי מקצוע פנויים באזור שלך

מערכת מלאה שמוצאת מי **פנוי עכשיו**, **קרוב אליך** ו**מתאים למה שאתה צריך** — ומאפשרת
להזמין אותו לזמן מדויק. נבנתה ללא תלויות חיצוניות: Python 3 (ספריית תקן בלבד) + SQLite + JS/HTML/CSS.

## הפעלה מהירה

```bash
python3 seed.py --reset        # יצירת נתוני דמו (48 אנשי מקצוע בגוש דן)
python3 -m pronear.server      # http://127.0.0.1:8000
```

### Windows

לפייתון על Windows אין מסד נתוני אזורי זמן מובנה, ובלעדיו מנוע הזמינות לא יכול לחשב
שעות מקומיות. התקנה חד-פעמית:

```powershell
pip install -r requirements.txt    # מתקין tzdata
python seed.py --reset
python -m pronear.server
```

אם הוא חסר, השרת נעצר מיד עם הסבר איך לתקן — במקום להיכשל בבקשת החיפוש הראשונה.

התחברות לדוגמה: `demo@pronear.demo` / `demo12345` (גם כל `proN@pronear.demo`, אותה סיסמה).

בדיקות:

```bash
python3 -m unittest discover -s tests -t .    # 113 בדיקות
```

## מה המערכת עושה

| יכולת | פירוט |
|---|---|
| חיפוש גאוגרפי | מרחק haversine אמיתי + סינון מקדים בתיבה תוחמת. שני הכיוונים נבדקים: הוא ברדיוס שלך, ואתה בתוך אזור השירות שלו |
| זמינות חיה | לוח שבועי חוזר פחות חסימות ידניות פחות הזמנות קיימות = חלונות פנויים אמיתיים |
| חיפוש לפי זמן | "עכשיו", "הכי מהר שאפשר", או תאריך ושעה מדויקים למשך עבודה נתון |
| דירוג התאמה | ציון 0–100 משוקלל, עם פירוק שקוף למשתמש (זמינות, קרבה, דירוג, מחיר, אמינות) |
| הזמנות | בחירת סלוט → בקשה → אישור/דחייה של איש המקצוע → סיום → ביקורת |
| הגנה על פרטיות | טלפון נחשף רק אחרי הזמנה מאושרת |
| אזור אישי | פרופיל, עורך לוח שבועי, חסימות זמן (חופשה/מילואים) |

## ארכיטקטורה

```
pronear/
  geo.py           מרחקים, תיבה תוחמת, הערכת זמן נסיעה
  timeutil.py      epoch ↔ זמן מקומי, חסין למעברי שעון קיץ
  availability.py  אלגברה של קטעי זמן: merge/subtract/clip, חלונות פנויים, סלוטים
  matching.py      פונקציות הציון והמשקלים
  services.py      לוגיקה עסקית: משתמשים, פרופילים, חיפוש, הזמנות, ביקורות
  api.py           ניתוב REST (דקורטור @route)
  server.py        שרת HTTP + הגשת קבצים סטטיים
  db.py/schema.sql SQLite: סכימה, טרנזקציות, חיבור פר-thread
web/               ממשק SPA בעברית (RTL), כולל מפת SVG מקומית ללא שירות חיצוני
tests/             113 בדיקות יחידה ואינטגרציה
```

### איך מחושב ציון ההתאמה

```
score = 36% זמינות + 26% קרבה + 22% דירוג + 10% מחיר + 6% אמינות
```

* **זמינות** — 100 למי שפנוי ברגע זה, ודועך לפי זמן ההמתנה לחלון הפנוי הבא.
* **קרבה** — דעיכה לינארית עד גבול החיפוש, עם בונוס למי שנמצא עד 2 ק״מ.
* **דירוג** — ממוצע בייסיאני (`prior` של 4 ביקורות בציון 4.0), כך ש-5★ בודדת לא מנצחת 4.8★ עם 200 ביקורות.
* **מחיר** — התאמה לתקציב שהוגדר; ללא תקציב הרכיב ניטרלי ולא מעניש יקרים.
* **אמינות** — אימות, ותק ומספר עבודות שהושלמו.

המשתמש רואה את הפירוק בכרטיס איש המקצוע — הדירוג לא "קופסה שחורה".

## API

| Method | Endpoint | תיאור |
|---|---|---|
| POST | `/api/auth/register` \| `/api/auth/login` \| `/api/auth/logout` | ניהול חשבון (טוקן Bearer) |
| GET | `/api/auth/me` | המשתמש המחובר + פרופיל מקצועי |
| GET | `/api/meta` | מקצועות, ימי שבוע, מיקום ברירת מחדל |
| GET | `/api/search` | `lat,lng,radius_km,profession,q,when=now\|at,at,duration,max_rate,min_rating,available_now,verified,sort` |
| POST/PUT | `/api/pros` \| `/api/pros/{id}` | יצירה/עדכון פרופיל מקצועי |
| GET | `/api/pros/{id}` | פרופיל ציבורי + זמינות + ביקורות |
| PUT | `/api/pros/{id}/availability` | לוח שבועי |
| GET | `/api/pros/{id}/slots` | סלוטים פנויים להזמנה |
| GET/POST/DELETE | `/api/pros/{id}/time-off` | חסימות זמן |
| POST/GET | `/api/bookings` | יצירה ורשימה |
| POST | `/api/bookings/{id}/status` | `confirmed\|declined\|done\|cancelled` לפי הרשאות |
| POST | `/api/bookings/{id}/review` | דירוג 1–5 אחרי סיום |

דוגמה:

```bash
curl "http://127.0.0.1:8000/api/search?lat=32.0853&lng=34.7818&radius_km=10&available_now=1&sort=soonest"
```

## החלטות תכנון

* **אין הזמנות כפולות** — הבדיקה והכתיבה רצות ב-`BEGIN IMMEDIATE` אחד, כך ששני לקוחות לא יתפסו את אותו סלוט.
* **בקשה ממתינה תופסת מקום** — `pending` ו-`confirmed` חוסמים את הלוח; `declined`/`cancelled` משחררים אותו מיד.
* **זמן מקומי, לא UTC נאיבי** — הלוח השבועי מורחב על שעון הקיר, כך ש-09:00 נשאר 09:00 גם בשבוע מעבר השעון.
* **סיסמאות** — PBKDF2-SHA256, 120K סיבובים, salt אקראי לכל משתמש; סשנים עם תפוגה.
* **מפה מקומית** — הדמיה ב-SVG לפי מרחקים אמיתיים, בלי לשלוח את מיקום המשתמש לשירות חיצוני.

## הרחבות אפשריות

גיאוקודינג של כתובות, התראות push/SMS, תשלומים ופיקדון, אימות תעודות בפועל, זמני נסיעה
אמיתיים במקום הערכה, ו-PostGIS/Redis כשמספר אנשי המקצוע גדל מעבר לרמת SQLite.
